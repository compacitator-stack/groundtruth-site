# Ground Truth — public site

Static site for the Ground Truth channel, served by GitHub Pages at
**https://gt.juliannieto.com**.

- `index.html` — landing page, the Five Gates method, and the report library
- `reports/` — full test reports. Not every episode has one yet, and a report goes up only
  once its episode is live, so the count here trails the channel rather than leading it.
- `7-questions.html` — free one-pager (unlisted; `noindex`, linked from the welcome email only)

Educational and entertainment content — not financial advice. See the disclaimer on every page.
